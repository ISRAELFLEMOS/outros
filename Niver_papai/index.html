Preparação & Exportação para GitHub Pages

1. Adicionar Fotografia do seu Pai (Opcional)

A foto escolhida abaixo fica apenas no seu navegador para pré-visualização imediata e já entra automaticamente como assets/images/pai.jpg no pacote .zip. A música já é 100% embutida no código (sem precisar subir MP3!).

2. Baixar Pacote ZIP Pronto para o GitHub (`aniversario-pai.zip`)

Gera a pasta completa com index.html, README.md, .nojekyll, a imagem assets/images/compartilhamento.jpg (1200×630 para WhatsApp) e a foto do seu pai caso selecionada acima.

3. Como publicar no seu GitHub (pelo navegador ou VS Code)

  1. Extraia o aniversario-pai.zip (ou use apenas o arquivo index.html se não for incluir foto).
  2. No GitHub, crie um repositório público chamado aniversario-pai e faça upload dos arquivos (ou dê push pelo VS Code).
  3. Vá em Settings → Pages, selecione Branch main e pasta / (root) e clique em Save.
  4. Aguarde 1 a 2 minutos, teste o link primeiro no seu próprio WhatsApp e depois mande para o seu pai!
